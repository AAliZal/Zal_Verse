# ZalVerse

**Don't just read science. Discover it.**

ZalVerse (زال‌ورس) is an interactive science learning platform. It lets students explore biology, chemistry, physics, and Earth & space through hands-on simulations, virtual experiments, a Persian periodic-table atlas, and a library of educational articles.

Open `index.html` in a browser and start exploring. No install step is required.

## Features

- Interactive simulations for biology, chemistry, physics, and Earth & space
- Search across card names, descriptions, and related keywords
- Subject filters
- Favorites, saved in the browser
- ZalBot, an on-site guide with day/night moods
- User profile with score, level, and discovered simulations (stored locally)
- Daily missions
- Light and dark theme, plus an animated sky background
- Random simulator, image gallery, and site stats
- Article library with 19 science articles
- Optional background music

Progress stays in the browser through `localStorage`. Nothing is sent to a server.

## Getting started

1. Open `index.html` in a modern browser.
2. Or publish the repo with GitHub Pages from the branch that contains `index.html`.

No Node.js or Python install is needed. `Web files/Mohasebe.py` is only a local helper that counts lines and file sizes.
